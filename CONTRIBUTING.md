# Contributing to Simple Interest Calculator

Thank you for your interest in contributing! All contributions are welcome, including bug reports, bug fixes, documentation improvements, feature enhancements, and new ideas.

## How to Contribute

### Reporting Bugs
- Open an issue on GitHub.
- Describe the problem clearly, including the steps to reproduce it, the expected result, and the actual result.
- Include your Python version and operating system if relevant.

### Fixing Bugs
1. Fork this repository.
2. Create a new branch: `git checkout -b fix/your-bug-name`
3. Make your changes and test them.
4. Commit your changes with a clear message.
5. Push your branch and open a Pull Request.

### Improving Documentation
- Fix typos, clarify instructions, or add examples to the README or other docs.
- Documentation pull requests are just as valuable as code changes.

### Suggesting Enhancements and Ideas
- Open an issue and describe your idea and why it would be useful.
- Examples: support for compound interest, input validation, a graphical interface.

### Submitting Pull Requests
1. Keep each pull request focused on one change.
2. Follow the existing code style.
3. Update the documentation if your change affects how the tool is used.
4. Describe what you changed and why in the pull request description.

## Code of Conduct
Please follow our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.

## Questions
If you have any questions, feel free to open an issue. Every contribution, big or small, is appreciated!
