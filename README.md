# github-final-project

A simple command-line tool written in Python that calculates simple interest.

## Features
- Calculates the interest earned on a principal amount
- Shows the total amount after the given time period

## Formula
```
Interest = (Principal x Rate x Time) / 100
Total    = Principal + Interest
```
- **Principal (P):** the initial amount of money
- **Rate (R):** annual interest rate in percent
- **Time (T):** time in years

## Requirements
- Python 3.x

## How to Run
```
python simple_interest.py
```

## Example
Input:
```
Principal: 10000
Rate: 5
Time: 2
```
Output:
```
Interest: 1,000.00
Total amount: 11,000.00
```
